# ☕ Bean There — Specialty Coffee & Café

A premium, responsive café website designed and developed for **Bean There**, focused on specialty coffee, thoughtful food, and a warm cafe experience.

## 🌐 Live Demo

https://swagatobhandariofficial-cpu.github.io/bean-there/

## 💻 GitHub Repository

## ✨ Features

- Premium specialty coffee-inspired UI
- Fully responsive design
- Desktop, tablet, and mobile layouts
- Sticky navigation
- Mobile navigation menu
- Smooth hover animations and transitions
- Responsive image layouts
- Dedicated Home, About, Services, and Contact pages
- Interactive contact form
- Client-side form validation
- Real email delivery using Formspree
- Accessible navigation and semantic HTML
- Optimized SCSS architecture
- GitHub Pages deployment

##🎨 **Design**

Bean There uses a premium dark café aesthetic with:
Deep charcoal background
Warm coffee-gold accent color
Elegant serif typography
Clean modern sans-serif body text
Large editorial-style headings
Spacious layouts
High-quality coffee imagery
Subtle motion and hover interactions
The design was created to give the website a sophisticated specialty-coffee brand identity.



##📱 **Responsive Design**

The website is designed to work across:
Desktop
Laptop
Tablet
Mobile devices
The layout, navigation, typography, images, cards, forms, and spacing adapt according to screen size.



##📩 **Contact Form**

The contact form uses Formspree to handle real email submissions.
The form includes:
Name validation
Email validation
Subject validation
Message validation
Submission status feedback
Successful email delivery



##🚀 **Deployment**

The website is deployed using GitHub Pages.
Every update can be pushed to the main branch and published through GitHub Pages.
